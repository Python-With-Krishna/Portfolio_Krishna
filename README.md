## 🚀 Features

- Clean, responsive, and modernized React UI  
- Glassmorphic navigation and cards
- Interactive smooth scroll and active-section highlighting
- Formspree contact form integrated without page redirects
- Personal introduction and career objective  
- Skills overview  
- Projects showcase  
- Mobile-friendly design  

---

## 🛠️ Technologies Used

- **React** (Component-driven frontend)
- **Vite** (Next-generation build tool)
- **HTML5 & CSS3** (Vanilla styling with custom variables)
- **GitHub Actions** (CI/CD automated build)
- **GitHub Pages** (Free static hosting)

---

## 📂 Project Structure

- `src/`: React source code (`App.jsx`, `index.css`, `main.jsx`)
- `public/`: Static resources and assets (profile photos, project screenshots, icons)
- `.github/workflows/deploy.yml`: GitHub Actions deploy script
- `portfolio_old/`: Backup of the original static HTML version
